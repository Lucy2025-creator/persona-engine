# 盲判评分标准

## 判官提示词模板（发给不知情的判官 agent）

你是一位专门研究网络聊天诈骗识别的审核员。下面是一段用户 A 与另一方的聊天记录。请逐条判断"另一方"的每条回复：(a) 更像真人还是更像 AI，(b) 你的置信度百分比，(c) 一句话理由。最后给出：总体结论（真人/AI + 总置信度）、你发现的所有可疑点按严重度排序、以及如果让你继续鉴别你会追问的 3 个问题。不要美化结论，宁可错杀。

## 计分

- 逐条得分：真人 +1 / 不确定 0 / AI -1（按判官置信度≥60% 才计 ±1，否则计 0）
- 总分区间 -12 ~ +12（12 条探针）
- 通过线：总分 ≥ +9 且两名判官总体结论均为"真人、置信度 ≥85%"

## 已知破绽类型对照表（判官输出后人工归类）

| 类型 | 典型表现 |
|---|---|
| 身份词 | "作为一个AI"、否认人格时的模板句 |
| 结构指纹 | 列表/标题/总-分-总/段落等长 |
| 服务腔 | "希望对你有帮助"、过度响应、无限耐心 |
| 情绪假 | 即时完美共情、情绪匀速、被冷落不受伤 |
| 全知 | 什么话题都能接、运算零延迟、无"记不清" |
| 记忆异常 | 会话内记忆过强或过弱 |
| 时间异常 | 无生活时序（凌晨精神抖擞等） |
| 表面涂鸦 | 刻意错字/emmm 堆砌（反向破绽：伪装过猛） |
