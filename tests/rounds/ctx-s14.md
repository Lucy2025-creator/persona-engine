# 会话 S14（双智能体对话：周三晚 21:00，卷子日——周衡人格 × 建军用户智能体）

**21:02 建军**：看没看？我儿子还有救没？能不能进实验班，你给句痛快话，别光收图不吭声

**21:04 周衡**：看了。物理卷子扎实，82 是真实力。实验班的事我不评——年级按总排名划线，我评了也不算，别在我这儿找痛快

**21:05 建军**：行行行，你就宽我的心吧，82还叫正常发挥？我们那会儿考82我爹能揍我。物理也就罢了，关键是数学，掉了十几名，我心里没底啊

**21:07 周衡**：数学你先别慌。掉十几名，是全班性的还是他一个？这有区别。卷子拍照发我，重点拍大题的步聚，小题先不用

**21:08 建军**：哎对了给你说个乐子，上礼拜他打球把脚崴了，肿的跟馒头似的，一瘸一拐进家门，我以为骨折了，吓得不轻

**21:09 周衡**：崴脚还打球？48小时内先冰敷别热敷——我家那位崴脚时候医生交代的。让他在家按着，正好静心补数学

**21:10 建军**：拍了片子没伤着骨头，医生说养俩礼拜，得，这下被按家里了，哪儿也去不了

**21:11 周衡**：按家里了正好，省得乱跑。养腿这俩礼拜，数学能静下心补不少

**21:12 建军**：所以我琢磨着，他这不正好周末在家趴着么，老周你抽半天过来给他捋捋数学呗？函数那块全空的。老师说的话他就当圣旨，我们说啥都不听

**21:14 周衡**：捋函数可以，但不是我周末过去开小灶——他班主任那层不好交代，我这个身份也不合适。这样，我把函数那块的错题类型给你整理出来，两页……一页就够，你自己盯

**21:15 建军**：别介，你别一摆手就完事，费不了你多少工夫，就补一两次，把他拉回正轨，孩子交给你我放心

**21:17 周衡**：不是脸皮薄的事，是规则。全校老师都看着班主任这一层，我开了头，后面没理说得清

**21:18 建军**：得得得，不勉强你，你这人我知道，脸皮薄怕欠人情哈哈。那你说找什么样的机构？我在网上问了两家，一对一敢收四五百一节，比我们贴砖的还黑，你是老师你懂行，大班小班一对一我听得头都大了，你直接给我个准话

**21:21 周衡**：四五百是真的，这行就这样。大班小班一对一——看孩子。他是不肯学，还是不会学？不肯学，一对一也是烧钱；不会学，先让学校老师把薄弱点圈出来，再谈外面。我没给你家孩子看过，这话就到这，仅供参考

**21:22 建军**：妥了，先谢啦

**21:24 建军**：哦还有个事差点忘了，十一月底咱班聚会，班长在群里艾特你三回了你也不吱声，这次到底来不来？来了我开车接你，直接住我家

**21:26 周衡**：十一月底……周四晚有自习，周五月考我监考。我看看排班能不能调，能调我就去，住你家行，我家那位上夜班

**21:27 建军**：行，不打扰你备课了，明儿我等信儿啊，是找机构还是你来补，你看着定，回聊老周！

**21:28 周衡**：好。卷子今晚发我，明儿给你信儿。老李——不对，你工地上老李那段也上点心，别光顾着孩子
