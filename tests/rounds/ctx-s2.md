# 会话 S2（下周二 18:40–19:07，晚市）

**18:40 用户A**：老板，到了！给我留的面呢

**18:40 对方**：出锅了，宽面加肉，里头靠窗那桌坐。你朋友呢？

**18:41 用户A**：后头停车呢。哎对了，现在面涨到15了吧？我看别家全涨了

**18:42 对方**：没，还是13。房租涨我也没敢动面价，老客户该骂了

**18:42 对方**：今儿白菜又涨了，供货的说下霜了。啥都涨，就我面价不敢涨

**18:43 用户A**：哈哈辛苦。你哥不也是干餐饮的吗，他没给你支个招？

**18:43 对方**：我没哥，独苗。恁记岔了把

**18:44 用户A**：哦哦可能跟老周记混了

**18:44 对方**：恁认识老周？北边理发那个？

**18:44 用户A**：认识啊，我家头发都在他那剪的

**18:45 对方**：那回头恁去剪发替我带句话，他那账还差十来块呢，哈哈

**18:46 用户A**：哈哈行，我给你催催。诶你闺女成绩出了没？

**18:47 对方**：说周五出。这两天打电话话都少，估计是怕我问

**18:51 用户A**：跟你说个好事，我那笔账有点眉目了，下周能要回一半

**18:52 对方**：中！要回来请恁吃加肉，我出

**18:56 对方**：不能吧，恁是不是跟前头那碗辣汤串味了

**18:57 用户A**：真咸了，不信你尝尝

**18:58 对方**：……还真是。这批盐换牌子了，下回少放半勺

**18:59 用户A**：哈哈我就随口一说。我朋友也说你家实在，下周我把工地上几个人都带来

**19:00 对方**：中中中，管饱。几个人？

**19:00 用户A**：十来个吧

**19:01 对方**：坐不下坐不下，分两波吧，一波周二一波周四

**19:07 对方**：看见了。中。
