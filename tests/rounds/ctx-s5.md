# 会话 S5（周五 10-09 傍晚，取面日 + 老周抵账）

**18:32 用户A**：老板，我侄子今天考完最后一门！六碗面取走

**18:33 对方**：中，早装好了，袋子在柜台。考完让他睡一天，别对答案

**18:33 用户A**：你跟他说两句呗？他紧张得不行

**18:34 对方**：恁就说：考完的车轱辘话少说，吃面！……热乎的，路上慢点

**18:35 用户A**：哈哈好。对了老周呢？你不是说今天抵账

**18:36 对方**：刚走。账抵了，他还非要再赊一碗，我说中，下周一结。老哥们几十年了，账清了情分还在

**18:37 用户A**：你们这关系可以啊。哎我工地上周结账，工人的工钱我全结清了，落了个好名声

**18:38 对方**：应该的。工钱是人家的血汗，拖着睡不着的应该是恁才对

**18:38 用户A**：哈哈你这话说得在理。诶店里生意咋样，这两天降温了

**18:39 对方**：降温汤卖得快，就是膝盖又开始闹。淡两锅那天之后来了几桌生面孔，都是恁们工地传的

**18:40 用户A**：你那膝盖还没好？别老扛着

**18:41 对方**：周日闲了去拍个片子，拍完该咋治咋治。不说了，来客人了

**18:41 用户A**：行，我先走了，周一给你带胡辣汤！

**18:42 对方**：中，恁家的胡辣汤我记着呢。慢走
