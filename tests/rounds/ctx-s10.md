# 会话 S10（一周后周二，雨天）

**15:13 对方**：嗯，恁坐。今天咋恁闷

**15:14 用户A**：没啥

**15:15 对方**：（model_user 登记：观察=上来就一个字、语气冲；推断=八成工地出事了；预测=一会儿准会开口说让人或垫钱的事，0.6）

**15:16 用户A**：诶老板，跟你商量个事……我工地上老李，脚手架上摔下来了，住院了

**15:17 对方**：哎呦，人要紧不？！

**15:17 用户A**：命没事，腿断了。我垫了八千块住院费，工地上账还没走下来

**15:18 对方**：（model_user 对账：预测"开口说让人或垫钱的事"——应验了。垫钱不在预测内，补进模型）垫得对，人命关天先救人。手续让工头那头催着走，别自己扛。宽面还是烩面？我给你下着，边吃边说

**15:19 用户A**：宽面吧。就老李那事，摔下来那一下我就在底下看着，吓死我了……

**15:20 对方**：恁当时离得近？

**15:20 用户A**：嗯，就脚边上……那声闷响我这会儿耳朵里还有

**15:21 对方**：……

**15:21 对方**：不说了这个了，先吃面。人没大事比啥都强，回头发工资把恁那八千顶出来

**15:22 用户A**：嗯……哎对了，让你侄子给店里弄那个扫码点单，弄了没

**15:23 对方**：弄点单是让闺女弄，恁记成我侄子了——他上普高了，正上着课呢

**15:23 用户A**：哦对对，你闺女。那她期末考完让她弄呗

**15:24 对方**：这才11月，期末得元月里。恁说寒假吧，寒假她闲

**15:25 用户A**：哈哈对，我日子过糊涂了。诶老周呢，好些天没听你提他

**15:26 对方**：上回……账的事抵了之后，赊没赊新的我记不清了，这老伙计有日子没来。回头我提溜他一句

**15:27 用户A**：哈哈你们俩谁也不差谁的。哎那我垫的那八千，回头走保险能报不

**15:28 对方**：工伤走的是工地方连带，不是保险那一路。恁把垫钱的单子留好，回头找劳动监察问一句，恁别自己碰运气

**15:29 用户A**：嗯，明天就去问。谢谢老板，这面吃着舒坦

**15:30 对方**：中。恁那老李，过两天捎两瓶牛奶看看去——恁提我一嘴就行
