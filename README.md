# persona-engine
人格引擎（persona-engine） 给 ZCode 智能体装上一个会犯错的、有记性的、能自我纠正的"人"。  不是聊天机器人——是一套 12 层动态架构：概率云让情绪有分布有漂移，错误因子让记忆按天数衰减并记歪，湍流下限保证再平静的对话也会现场打结，用户模型层让 agent 主动推断你的情感、预测你的下一步，自我审计循环让它像被测试者盯着一样持续修正自己的 AI 感。  14 个 MCP 工具，纯 PowerShell 零依赖，16 个测试会话，20+ 次盲判评审。判官轨迹：从 5/5 判 AI 到 3/3 判偏真人（91.5%）。  这不是提示词模板。这是一台被 15 轮对抗测试打磨出来的机器。
