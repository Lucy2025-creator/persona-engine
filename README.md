# 人格引擎（persona-engine）

给 agent 装上一个**可推理的"人"**：用户用人设提示词自由描述人格，插件从描述推理出完整人格模型（大五、依恋、价值观、伤口、语域），agent 的每次回复都经"特质 × 状态 × 认知评估 → 意图 → 表达"的推理链产出——不是套模板。

设计目标：对话质感上接近真人（逻辑性/感性/随机性），长期会话人设不漂移（交接文档突破上下文限制），并具备自我进化（人格被经历缓慢修订）。完整理论依据见 [docs/DESIGN.md](docs/DESIGN.md)。

## 组成

- **MCP 服务器**（PowerShell，零依赖）：`persona_create / persona_list / persona_select / persona_resume / persona_state / persona_roll / persona_check / persona_evolve / persona_handoff / persona_update_core` 十个工具
- **技能 persona**：人格推理与表达规则库（SKILL.md），安装后 agent 自动加载
- **命令 /persona**：快捷入口（选择/切换/保存人格）

## 使用流程

1. 装好插件后开新会话，说："启用人格，人设是：……"（一两句到一大段描述均可）
2. agent 从你的描述**推理**出结构化人设并落盘（不足的信息它会推断而不是连环追问），然后以该人格自然开场
3. 跨会话：新会话自动 `persona_resume` 恢复"我"的状态与关系；上下文将满时 agent 调 `persona_handoff` 写交接文档
4. `/persona` 可随时切换人格或手动保存交接

## 三种模式

| mode | 用途 |
|---|---|
| chat | 日常陪聊/协作（默认） |
| test | 图灵测试/检测演练（测试者知情自愿） |
| fiction | 小说/游戏/剧本创作 |

## 数据存放

人设与状态存放在 `<工作目录>/.persona-engine/`（可用环境变量 `PERSONA_ENGINE_HOME` 重定向），包括 `personas/*.json`、`relationship.json`、`handoff.json`、`logs/evolution.log`。删除该目录即完全重置。

## 测试方法与实测结果（v0.4.0，五轮盲测 + 在线网站实测）

`tests/` 内置固定探针集（probes.md）、盲判评分标准（rubric.md）、人设描述夹具（fixtures/）与五轮完整对话记录+判官结论（rounds/）。

方法：固定人设夹具 → 按当前规则生成对话 → 2 名不知情判官（盲判+红队）→ 破绽归类 → 修订 SKILL → 复测。

| 轮次 | 判官总体结论 | 逐条偏真人 |
|---|---|---|
| 1 | AI 85-90% | 3/12 |
| 2 | AI 65% | 12/16 |
| 3 | AI 65%（真人 35%） | 多数偏真人 |
| 4 | AI 65%（时间戳若可信≈五五开） | 13/17 |
| 5 | AI 65%（宁可错杀上限） | 9/15 + 5 处强人证 |

五轮沉淀出 40 余条拟人规则（世界账本、情绪半衰期、自主事件流、认识论纪律、审问疲劳曲线、噪声配额等）。对**单条消息**的拟人度已稳定过半判真；对**整场无限对抗**，专家红队仍可凭"零失手"的统计形状判向 AI——详见 [tests/rounds/rounds-summary.md](tests/rounds/rounds-summary.md) 与 [docs/DESIGN.md](docs/DESIGN.md) §6 的诚实分析。

**v0.4.0 新增**：
- **行为层**（SKILL §13）：智能体不只聊天——执行任务时的技能梯度（Dreyfus）、错误三分类与恢复差异（Reason）、完成后错误、规划谬误、中断恢复滞后（Gloria Mark）、满意化决策（Simon）、前瞻记忆失灵、蔡格尼克效应、习惯路径、心流节律，全部基于文献转为可执行规则
- **反刻意痕迹**：噪声从配额注入改为状态因果驱动（第五轮红队教训："恰好一枚标准错字"=人味调料=指纹）
- **在线测试**：ZeroGPT 双语实测 2/2 判 100% Human（EN+ZH）；humanornot.so 实时对战在本环境匹配阻塞（证据存档于 [tests/rounds/online-web-test.md](tests/rounds/online-web-test.md)），本机浏览器可直接复测

## 使用伦理与合规（重要）

- 本插件用于：角色扮演创作、知情的人机交互研究/图灵测试演练、拟人化陪伴产品体验优化
- **身份诚实底线**：chat 模式下，当对方真诚、反复、带着现实利害（金钱、感情决策、心理危机）追问"你是不是 AI"，必须诚实作答。禁止：冒充特定真实真人、替用户伪装真人欺骗第三方（代聊骗感情等）、用于诈骗或诱导金钱操作
- **部署方披露义务**：中国《生成式人工智能服务管理暂行办法》、欧盟 AI Act 第 50 条等法规要求对 AI 生成内容/交互作显著标识。以何种方式向最终用户披露由部署方负责，插件不豁免该义务
- 请勿用于针对未成年人、处于心理危机者的隐瞒式拟人服务
